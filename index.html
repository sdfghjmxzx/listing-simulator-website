What is Listing Simulator?

A local workspace for the Excel catalog files Amazon gives you — with health, stock, and image tools built in, without uploading your workbook to the cloud.

Local & private

Open, edit, and save on your machine. Nothing is hosted on our servers. Your API keys for optional AI stay in your user profile.

Built for Amazon templates

Works with catalog reports (.xlsx, .xlsm, .xls). Find Catalog and Bind Rules keep the workbook aligned with Amazon’s sheet structure.

Clones, not raw Data rows

Edit working copies in Clones. Health Check and Export Health catch issues before you upload one family (or a few) — not the whole catalog at once.

Features

The game changers — from health to images to upload.

Health Check

Listing, inventory bars (Listing / SKU / Family), and gallery health — plus filters and Low stock. Catch missing Must fields before Amazon does.

Listing Creation

Create New Listing with Rules-driven Must fields, then Make variation to copy from a child or standalone and grow a family on Clones.

Stock, Ships & Package watch

Link an FBA Inventory Report for stock and Ships (FBA/FBM). Watch package size tiers (XS–4XL) with Pre 2027 / Post 2027 rules.

Image editor

Modify image: crop, zoom, aspect presets, and local background remove — plus gallery AI generate/customize when you connect your key.

Create Catalog

Build a local Families / Standalones folder and download listing images — a snapshot for your workflow, not an Amazon upload.

Export with health gate

Export focused clone feeds. Export Health flags likely rejects vs advisory gaps so you can fix or continue with eyes open.

Also included

  • Merge catalog — pull a fresh inventory file while keeping Clones, Notes, and history.
  • Compare mode — two listings side by side with cross copy/paste and AI context.
  • Pins — pin families to a Pinned panel for quick return.
  • View sheets — Data / Clones / Notes grids with filters, Lookup, and Save sheet.
  • Optional AI (Aleksa) — chat, field enhance, inventory scan, and gallery image tools with your own API key.

How it works

Typical flow from Seller Central to upload.

1

Get your catalog

Download an inventory / catalog report from Seller Central and save the Excel file. Optionally keep an FBA Inventory Report for stock and Ships.

2

Open & bind

Open catalog in Listing Simulator. Use Find Catalog and Bind Rules if the banners ask. Link FBA when you want Stock / Ships / Package watch.

3

Create & edit

Open a row or Create New Listing. Create Clone, edit copy and gallery (Modify image), run Health Check, then Save.

4

Export with health review

Export one family (or a few). Review Export Health (likely rejects vs advisory), open the file, then upload to Amazon.
